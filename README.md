# CAS-Bridge-Diffusion
Continual learning via Bridge Diffusion: a Compress–Add–Smooth recursion that encodes temporal memory as a stochastic process on [0,1]. Retention scales as a₁/₂ ≈ cL with c > 1 (beating FIFO by ~2.4×), independent of mixture complexity K. PyTorch, O(LKd²) per day, no backprop.
